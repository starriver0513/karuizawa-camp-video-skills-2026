Claude Code で使う
動画作成スキル3種

語り系動画の編集、図解解説動画、30秒のPV動画を作るスキルです。ZIPを入れて「セットアップして」と伝えると、パソコンの確認、足りない物の案内、テスト出力まで進みます。Codex でも使えます。

SKILL 01語り系動画のAI編集話している動画を、自分の編集の型でカット・テロップ・効果音まで入れる SKILL 02図解解説動画顔を出さずに、図解とAIの声で解説動画を作る SKILL 03PV動画告知の内容と画像から、30秒のPV動画を作る

3本に共通する入れ方

入れる前に用意する物

パソコンMac または Windows
Claude Code
または Codex		Claude Code はデスクトップアプリかターミナル版のどちらか。Codex でも同じスキルが動きます
そのほかスキルごとに必要な物（ffmpeg・Node.js・Python のライブラリなど）は、セットアップの中で確認して案内します。先に入れておく必要はありません。Premiere Pro と Gemini の APIキーは、無くても使えます

入れ方（3つ）

  1. ZIPをダウンロードする各スキルの「ZIPをダウンロード」ボタンから保存します。
  2. ZIPを Claude Code に渡して、こう伝える このZIPをスキルとして入れて、セットアップして Claude Code が解凍して、スキルの置き場所（Mac は ~/.claude/skills/、Windows は C:\Users\自分の名前\.claude\skills\）へ置きます。Codex の場合は ~/.codex/skills/ です。自分で置く場合も、この場所へ解凍したフォルダごと入れ、Claude Code / Codex を開き直します。
  3. 案内に沿って進める足りない物があれば、入れてよいかを聞いてから入れます。APIキーの入力やアプリの購入など、自分で行う所は手順を1つずつ案内します。

セットアップで行うこと

01 確認パソコンの中を調べる

必要なアプリ・ツール・APIキーがあるか、版が足りているかを一覧で出します。

02 自動で入れる入れてよいか聞いてから入れる

Homebrew・winget・npm で入る物は、了承をもらってから入れます。

03 案内する自分で行う所は手順を出す

Homebrew の初回導入や APIキーの発行など、自分で操作する所は1つずつ案内します。APIキーは画面に表示せずに保存します。

04 テスト出力短い動画を1本書き出す

書き出した動画の長さと中身を確かめて、使える状態になったかを判定します。

SKILL 01

語り系動画のAI編集

話している動画を、あなたの編集の型で仕上げる

解説動画（約1分）は準備中です

できること

01カット

長い間、「えー」などのつなぎ言葉、言い直しを見つけて切ります。

02テロップと効果音

文字起こしからテロップと効果音を入れ、音量をそろえます。文字起こしはパソコンの中だけで行うので、APIキーは要りません。

03自分の型を覚える

自分の Premiere のプロジェクトか、自分の完成動画から、テロップの位置・大きさ・色・カットの間を読み取って案を出します。了承した物だけが保存されます。

作れる動画の見本: 語り系動画（YouTube）

入れると変わること

自分の型を一度覚えさせると、次の動画からその型で編集されます。直してほしい所を伝えれば、その内容が記録され、次の編集から反映されます。編集にかかる時間を短縮できると、発信を続けやすくなります。

書き出しは、完成した mp4 と、Premiere で開いて手直しできるファイルの両方です。仕上げだけ自分の手で整えることもできます。

使い方の流れ

  1. 自分の型を渡す自分で編集した Premiere のプロジェクトか、自分の完成動画を渡します。YouTube に上げた動画は、YouTube Studio から自分の動画をダウンロードして渡します。他人の動画は材料にしません。
  2. 型を確認する「今の値 → 案」と根拠の一覧を見て、了承した物だけを保存します。
  3. 撮った動画を渡す「この動画を編集して」と伝えます。どこを切るかの案を一緒に見直してから書き出します。
  4. 直してほしい所を伝える毎回同じになる意見は、了承を取って型に足します。次の編集から反映されます。

SKILL 02

図解解説動画

顔を出さずに、図解とAIの声で伝える

解説動画（約1分）は準備中です

できること

01要望を聞いて台本を作る

誰に何を伝えるか、長さや縦横を聞き取り、台本を出します。

0215秒の見本を先に見せる

見た目を確かめてから全編に進みます。

03見た目を選べる

色は5種類から選べます。自分の写真、効果音、声も選べます。選んだ内容は保存されます。

作れる動画の見本: 図解動画（動画ファイルが開きます）

入れると変わること

台本、図、声、効果音を一人でそろえる手間がなくなります。声は Gemini の読み上げを使うので、自分で話して録る必要はありません。Gemini の APIキーが無い時は、Mac の読み上げか声なしでも作れます。一度選んだ色・写真・効果音は保存されるので、2本目以降も同じ見た目で作れます。

使い方の流れ

  1. 「解説動画を作りたい」と伝えるテーマ、見てほしい人、長さ、縦か横かを聞かれるので答えます。
  2. 台本を確認する画面に出す文字と読み上げの文が表で出ます。直したい所を伝えます。
  3. 15秒の見本を見る色・写真・効果音・声を決めます。
  4. 全編を書き出す書き出した動画の長さと音量を確かめて渡されます。

SKILL 03

PV動画

告知の内容と画像から、30秒の動画を作る

解説動画（約1分）は準備中です

できること

01企画を3案出す

何の告知か、誰に向けるか、使う画像から、方向の違う3案を出します。

02秒ごとの台本を作る

何秒に何を出すかを、文字の台本で決めます。

03書き出しと検品

Remotion で書き出し、秒数や文字の切れを確かめます。APIキーも有料サービスも使いません。

作れる動画の見本: PV動画（X）

入れると変わること

実際に30秒のPVを作った時の手順と、直して分かったこと（動きの速さ・音の大きさ・検品で見る所）をスキルの中に入れてあります。色・文字・動き・音を先に文字で決めて確認してから書き出すので、出来上がってから全部作り直すことが減ります。

使い方の流れ

  1. 告知の内容と画像を渡す日時・対象・伝えたいこと・使いたい画像を渡します。
  2. 企画を1つ選ぶ3案から選び、直したい所を伝えます。
  3. 秒ごとの台本と見た目を確認する色・文字・動き・音を文字で確認します。
  4. 書き出しを受け取る1920×1080 の mp4 が書き出され、検品の結果と一緒に渡されます。

うまく進まない時

セットアップの途中で止まった

Claude Code に「セットアップの続きをして」と伝えます。すでに入った物は飛ばして、足りない物だけ案内します。

スキルが呼ばれない

フォルダの置き場所を確認します。~/.claude/skills/スキル名/SKILL.md の形になっているかを Claude Code に確認してもらうのが早いです。置いた後は Claude Code を開き直します。

APIキーをどこに入れればよいか分からない

APIキーが要るのは、図解解説動画で Gemini の声を使う時だけです。セットアップの中で、ターミナルで実行するコマンドを案内します。貼り付けた値は画面に表示されず、作業フォルダの .env に保存されます。チャットにAPIキーを貼らないでください。

Windows で使えるか

セットアップの中で、Windows 用の入れ方（winget など）を案内します。動作の確認は Mac で行いました。Windows で止まった時は、表示をそのまま Claude Code に見せてください。
